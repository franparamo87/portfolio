## 🛠️ Stack Tecnológico de la Web
Para este proyecto he decidido utilizar un stack moderno, ligero y altamente performante:

* **HTML5 & CSS3**: Estructura semántica.
* **Tailwind CSS**: Framework de utilidades para un diseño moderno, responsive y con soporte nativo para **Dark Mode**.
* **JavaScript (ES6+)**: Lógica para el cambio de idiomas (ES/EN) y gestión de temas.
* **AOS (Animate On Scroll)**: Implementación de animaciones suaves para mejorar la experiencia de usuario (UX).
* **FontAwesome 6.4**: Iconografía técnica detallada.

## 💼 Resumen Profesional Destacado
En la web detallo mi experiencia en proyectos de alta criticidad como:

- **Agencia Tributaria (AEAT)**: Desarrollo de Apps con alta concurrencia como Renta y Clave PIN.

## 🏗️ Arquitectura del Proyecto
El código sigue principios de limpieza y mantenibilidad:
- **Diseño Mobile-First**: Totalmente adaptable a cualquier dispositivo.
- **Internacionalización (i18n)**: Sistema integrado para alternar entre Español e Inglés sin recargar la página.
- **Accesibilidad**: Uso de contrastes adecuados y etiquetas semánticas.
